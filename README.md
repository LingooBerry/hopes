**HopeS - Charity and Donation Website System**

HopeS is a web-based charity and donation platform designed to enhance donor engagement, retention, and participation. It aims to create an interactive user experience for donors and volunteers, while promoting transparency and social responsibility.  

**Overview**
Millions of people were pushed into poverty during the pandemic and global crises, making charitable donations more critical than ever. However, many nonprofit websites face challenges such as poor user interface, limited donor interaction, and lack of contribution tracking, which reduce donor trust and engagement.  

**HopeS addresses these issues by providing**
1. A user-friendly interface for donations and volunteering.
2. Donation dashboards to track donation history and engagement levels.
3. Real-time impact pop-up messages to show the effect of contributions.
4. Volunteer sign-up pages and campaign descriptions for better engagement.  

The system follows the Software Development Life Cycle (SDLC) methodology to ensure structured development, testing, and deployment.

**Features**
1. User Donation Dashboard - Track past donations, engagement points, and levels.
2. Volunteer Sign-up Page - Browse and register for volunteer opportunities.
3. Donation Campaign Page - View campaigns, progress bars, and impact messages.
4. Real-time Updates - Donation history and campaign statistics updated instantly.
5. Gamification - Earn points for donations and reach higher engagement levels.
6. Easy Navigation - Clean and intuitive user interface for all age groups.  

**Technologies Used**
1. Frontend - HTML, CSS, JavaScript
2. Backend - PHP
3. Database - MySQL
4. Development Tools - XAMPP (Apache & MySQL), phpMyAdmin, Visual Studio Code
